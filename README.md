# resavo-legal

Öffentlich gehostete Datenschutzerklärung und Nutzungsbedingungen für die RESAVO-App, verlinkt aus dem Paywall-/Store-Setup (RevenueCat, App Store Connect, Google Play Console) und aus der App selbst (`src/config/legal.ts` im [resavo-app](https://github.com/mm06dev/resavo-app)-Repo).

Quelltext (Markdown, zum Bearbeiten) liegt im Haupt-Repo unter `docs/legal/`. Änderungen dort müssen manuell in die HTML-Dateien hier übernommen werden — inklusive der englischen Fassungen (`privacy-english.html`, `terms-english.html`), die für RevenueCat benötigt werden und von Hand übersetzt sind, keine automatische Übersetzung.

Gehostet über GitHub Pages aus diesem Repo (Settings → Pages → main branch, root).
